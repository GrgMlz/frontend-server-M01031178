# After School Frontend

This is the Vue.js frontend for my after school classes app (CST3144 coursework). It shows the lessons, lets you sort them, add them to a cart and check out, and it gets its data from my Express server on Render.

- GitHub repo (Vue.js app): https://github.com/GrgMlz/frontend-server-M01031178
- GitHub Pages link (Vue.js app): https://grgmlz.github.io/frontend-server-M01031178/
- GitHub repo (Express.js app): https://github.com/GrgMlz/backend-server-M01031178
- Render route that returns all the lessons: https://backend-server-m01031178.onrender.com/lessons
